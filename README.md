# Grocery-delivery-revenue-analysis
Product analytics case: investigation of a revenue decline in a grocery delivery service
# Анализ причин падения оборота сервиса доставки продуктов
## О проекте
Итоговый учебный проект по продуктовой аналитике в Т-Академии.
Цель исследования - определить причины снижения оборота сервиса доставки продуктов в последнем месяце и сформулировать рекомендации для продуктовой команды.
## Данные
Исходные данные предоставлены в рамках учебного проекта и не публикуются в репозитории.
## Стек
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
